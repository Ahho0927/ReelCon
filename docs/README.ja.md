# ReelCon

Instagram投稿写真のダウンロードとデスクトップ向け動画操作を追加するManifest V3 Chrome拡張機能です。

## 機能

- ホームフィードと投稿画面でInstagramが提供する最高解像度の写真をダウンロード
- 写真にカーソルを合わせ、右下ボタンで保存。カルーセルは表示中の写真のみ対象
- 動画の中央をホールドすると、UIを隠して一時停止
- 動画の左右サイドをホールドすると2倍速で再生
- 端をホールドしたまま下にスライドすると、2倍速をロックまたは解除
- 動画下部の白いシークバーをクリックまたはドラッグして再生位置を移動
- ホームフィード写真、個別・モーダル投稿、リール、フィード動画に対応
- 英語、日本語、韓国語、簡体字中国語、繁体字中国語に対応

## インストール

1. ReleasesページからZIPファイルをダウンロードします。
2. ZIPファイルを展開します。
3. Chromeで`chrome://extensions`を開きます。
4. **デベロッパーモード**を有効にし、**パッケージ化されていない拡張機能を読み込む**をクリックして、展開したフォルダーを選択します。

## 注意事項

ReelConは独立したプロジェクトであり、InstagramまたはMetaとの提携、承認、スポンサー関係はありません。
