# ReelCon

這是一款 Manifest V3 Chrome 擴充功能，可為 Instagram Reels 和首頁動態影片加入適合桌面操作的長按手勢與精準進度列。

## 功能

- 長按影片中央可隱藏介面並暫停播放
- 長按影片左側或右側邊緣可進行 2 倍速播放
- 長按邊緣並向下滑動可鎖定或解除 2 倍速
- 點擊或拖曳影片底部的白色進度列可跳轉播放位置
- 支援 Reels、首頁動態影片，以及從首頁開啟的貼文彈出視窗
- 支援英文、日文、韓文、簡體中文和繁體中文

## 安裝

1. 從 Releases 頁面下載 ZIP 檔案。
2. 解壓縮 ZIP 檔案。
3. 在 Chrome 中開啟 `chrome://extensions`。
4. 啟用**開發人員模式**，點擊**載入未封裝項目**，然後選擇解壓縮後的資料夾。

## 注意事項

ReelCon 是一個獨立專案，與 Instagram 或 Meta 不存在任何從屬、認可或贊助關係。
