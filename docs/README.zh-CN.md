# ReelCon

这是一款 Manifest V3 Chrome 扩展程序，可为 Instagram Reels 和主页动态视频添加适合桌面端的长按手势与精准进度条。

## 功能

- 长按视频中央可隐藏界面并暂停播放
- 长按视频左侧或右侧边缘可进行 2 倍速播放
- 长按边缘并向下滑动可锁定或解除 2 倍速
- 点击或拖动视频底部的白色进度条可跳转播放位置
- 支持 Reels、主页动态视频以及从主页打开的帖子弹窗
- 支持英语、日语、韩语、简体中文和繁体中文

## 安装

1. 从 Releases 页面下载 ZIP 文件。
2. 解压 ZIP 文件。
3. 在 Chrome 中打开 `chrome://extensions`。
4. 启用**开发者模式**，点击**加载已解压的扩展程序**，然后选择解压后的文件夹。
