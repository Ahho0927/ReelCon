# ReelCon

这是一款 Manifest V3 Chrome 扩展程序，可下载 Instagram 帖子照片并添加桌面端视频控制功能。

## 功能

- 在主页动态和帖子页面下载 Instagram 提供的最高分辨率照片
- 将鼠标移到照片上并使用右下角按钮保存；轮播仅下载当前照片
- 长按视频中央可隐藏界面并暂停播放
- 长按视频左侧或右侧边缘可进行 2 倍速播放
- 长按边缘并向下滑动可锁定或解除 2 倍速
- 点击或拖动视频底部的白色进度条可跳转播放位置
- 支持主页照片、单独及弹窗帖子、Reels 和主页视频
- 支持英语、日语、韩语、简体中文和繁体中文

## 安装

1. 从 Releases 页面下载 ZIP 文件。
2. 解压 ZIP 文件。
3. 在 Chrome 中打开 `chrome://extensions`。
4. 启用**开发者模式**，点击**加载已解压的扩展程序**，然后选择解压后的文件夹。

## 注意事项

ReelCon 是一个独立项目，与 Instagram 或 Meta 不存在任何隶属、认可或赞助关系。
