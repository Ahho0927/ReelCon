# ReelCon

Instagram 게시물 사진 다운로드와 데스크톱용 영상 제어 기능을 제공하는 Manifest V3 Chrome 확장 프로그램입니다.

## 기능

- 홈 피드와 게시물 화면에서 Instagram이 제공하는 최고 해상도 사진 다운로드
- 사진에 마우스를 올려 우측 하단 버튼으로 저장하며 캐러셀은 현재 사진만 다운로드
- 영상 중앙을 홀드하면 UI를 숨기고 일시정지
- 영상 좌우 가장자리 영역을 홀드하면 2배속
- 가장자리를 홀드한 채 아래로 밀면 2배속 고정/해제
- 영상 하단의 흰색 탐색 바를 클릭/드래그해서 탐색
- 홈 피드 사진, 개별·팝업 게시물, 릴, 홈 피드 영상 지원
- 영어, 일본어, 한국어, 중국어 지원

## 설치

1. Release 페이지에서 zip 파일을 다운 받습니다.
2. zip 파일을 압축해제합니다.
3. Chrome에서 `chrome://extensions`로 들어갑니다.
4. Developer Mode를 활성화한 다음 Load unpacked을 눌러 압축해제한 폴더를 등록합니다.

## 참고 사항

Reel Controls는 Instagram 또는 Meta와 제휴하거나 승인을 받은 제품이 아닙니다.
